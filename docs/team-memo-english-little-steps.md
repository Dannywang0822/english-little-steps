## 1. 项目定位

- **产品名**：英语小步走（从 KET 起步）
- **使用者**：Danny 自己孩子（初一，尚未过 KET）
- **性质**：轻量个人学习 H5，不做复杂商业化、拉新漏斗或大团队招聘
- **长期目标**：雅思约 8 分；**当前只做阶段 0 启蒙 + 阶段 1 KET**，雅思高阶路线过 KET 后再启用
- **日课**：约 15–20 分钟起步；已调整为日课上限约 40 分钟（复习超 24 分钟停新学）

## 2. 学习方法论（专家口径）

- **主路径**：词块 / 搭配；话题阶段 0/1 为：学校生活、家庭与日常、食物与爱好
- **过关**：教育学专家已给出阶段 0 / 阶段 1 KET 过关标准；写入 `docs/methodology-final.md`（v3+AWL；左滑规则见后续 v4）
- **AWL**：跨主题日限 1
- **左滑**：未记住按记忆曲线回排复习；规则由教育学专家制定，H5 实现后需专家审再上线
- **读音**：`speechSynthesis`，优先 en-GB（已上线）

## 3. 首页 / 打卡 UX（Danny 已拍板）

| 区块 | 规则 |
|------|------|
| 今日主题 | 打卡卡片顶部；当天新学与造句只用该主题 |
| 每日任务（硬性打卡） | 复习、新学、造句、收工四项；显示进度如「新学 5/10」；未完成醒目；**四项全完成才算当天打卡并计入连续天数** |
| 主题点亮 | 长期进度，放下方；累计每日造句 |
| 最近 7 天 | 打卡记录；去掉重复进度区块 |

### 每日学习量

- 新学 **8–12** / 主题（**每个主题各**上限，非三主题合计）；前一天该主题左滑过半 → 次日该主题新学降为 **8**
- 造句 **8–10**
- 日课上限约 40 分钟；复习超 24 分钟停新学

## 4. 路线图进度（已结案 · 2026-10-15 · b471a3e）

Danny 需求：**路线图增加「时间进度」+「已打卡进度」**。

**群内已确认口径（专家 2026-10-15）：**

- **时间进度**：自首次学习日起，阶段 0 **计划约 84 天（12 周）** 日历展示
- **已打卡进度**：实打卡天数相对 **目标打卡 60** + 连续天数（与四项全完成规则一致）
- **重要**：84 / 60 是「计划窗 / 期望打卡量」，**不是阶段 0 过关门槛**。过关仍按能力（留存 + 词库造句 + 短连续）；能力到了可提前点亮出关，不必等到第 84 天。
- **文案**：面板标「计划约 84 天」「目标打卡 60」，**不要**写成「还剩 X 天才算完成」。
